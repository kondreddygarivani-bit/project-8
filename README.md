Basic RAG Model Project
Problem Statement

Build a chatbot that answers questions from your own documents instead of using only general LLM knowledge.

Tools & Technologies
Python
LangChain
FAISS (Vector Database)
Sentence Transformers
Hugging Face
Transformers

Workflow of RAG:
User Question
      ↓
Convert Question to Embedding
      ↓
Search Similar Chunks in Vector DB
      ↓
Retrieve Relevant Text
      ↓
Send Context + Question to LLM
      ↓
Generate Final Answer


Learning Outcomes

After completing this project, you will learn:

Text chunking
Embeddings
Vector databases
Semantic search
Retrieval
LLM prompting
Basic RAG pipeline
